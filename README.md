# Photo2Solid

**Automatic 3D reconstruction from a single photograph**

Photo2Solid is a desktop application that transforms a 2D image into a 3D model. It brings image enhancement, AI-based reconstruction, and mesh optimization together in one workflow, with options to run locally or on Google Cloud.

## Highlights

- Upscales and restores input images with Real-ESRGAN and Restormer.
- Reconstructs 3D geometry from a single image with Wonder3D+.
- Optimizes meshes and exports GLB, OBJ, and STL files.
- Includes an interactive 3D viewer and tools for preparing models for 3D printing.
- Supports local GPU processing and Google Cloud Vertex AI jobs.

## Technology

Python, PySide6, PyTorch, Wonder3D+, Restormer, Real-ESRGAN, Docker, Google Cloud, and Three.js.

## Project

Developed as a diploma project in 2026. The application was evaluated on six image subjects with varied shapes and textures.

*Model weights and cloud credentials are not included.*
